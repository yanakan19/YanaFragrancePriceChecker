# Repository tidy, 9 October 2026

The owner asked for the repository to be cleaned up and reorganised. The
branch it lives on (`claude/scentday-retailer-registry-h92tth`) is live:
GitHub Pages deploys from it and the UK, US and India crawls, the link, image,
Awin and price check workflows push to it all day. So this tidy is
behaviour preserving and deliberately small: nothing the site, a crawl or a
deploy reads was moved, and every step was checked (typecheck, `npm run demo`,
the tests) before the next.

Cut from the live tip `470faead` on branch `tidy-20261009`. This file is the
survey (written first, before any change) and the record of what was done
and what was left alone.

## 2. Dead or orphaned

**Scripts.** Every one of the 126 files in `scripts/` was checked against
`package.json`, the 16 workflows, `scripts/generated-files.txt`, imports from
`scripts/`, `src/`, `demo/` and `tests/`, and every mention in docs, social
notes and code comments. None is dead:

- `scripts/deploy-decision.d.mts` and `scripts/deploy-watchdog.d.mts` are
  named by nothing, but they are the type declarations TypeScript uses when a
  test imports the `.mjs` files beside them. Kept.
- `scripts/social-explainers.ts`, `social-how-prices-work.ts`,
  `social-intro-slides.ts`, `social-savings-example.ts`,
  `social-hurry-video.ts` are the scripts that first made particular posts.
  `social/README.md` and the posts' `source.md` tell the owner to run them to
  remake a post, and `scripts/generated-files.txt` names "the post scripts
  (scripts/social-*.ts)" as writers of the social pictures. Kept in place.
- `scripts/id-alias-seed.sh`, `scripts/recover-stale-checkout.sh`,
  `scripts/backup-worktree.sh`, `scripts/logo-ink.py`: run by hand or by the
  session start hook, and named in docs. Kept.
- `scripts/concentration-report.ts`, `name-noise-report.ts`,
  `gender-coverage.ts` (read only analysis reports, run by hand, named only in
  code comments) and the two image backfills `image-size-backfill.ts` +
  `image-size-read.py`, `silhouette-backfill.ts` + `silhouette-read.py` (one
  off backfills, named only in docs and comments): not dead, but one offs.
  Proposed move to `scripts/oneoff/` (section 5).

**Docs.** Superseded dated reports and plans, named only from the old docs
index (or by nothing): `BACKLOG-2026-08-20.md` (a backlog from 20 August),
`REFINEMENT.md` (the 1 August refinement plan, "29 of 29 listings"),
`design-brief.md` (marks itself historical; the revamp shipped),
`TRUSTPILOT-REVIEW-2026-10-04.md` (its findings are in the registry),
`PR5-NOTINO-REVIEW-2026-10-08.md` (a one-off review of PR 5). These are
history, so they are archived, not deleted (section 5).

Dated reports that code comments or `src/` link to (`SPIKE-RESULTS.md`,
`INGESTION-AUDIT.md`, `MICROCOPY-INVENTORY-2026-08-21.md`,
`LOGO-PROBE-REPORT.md`, `FRAGRANTICA-LINK-AUDIT-2026-10-05.md`,
`SHOP-PROBES-2026-10-08.md`, `BLOCKED-SHOPS-ROUTES-2026-10-08.md`, the
retailer candidate lists, `FAILED-RUNS-ANALYSIS.md`,
`history-rewrite-2026-10-06-commit-map.txt`) stay where they are: moving them
means editing comments in `src/`, `demo/` and the workflows for no gain. The
index lists them under "Dated reports".

`docs/DELIVERY-RECHECK.md` is written by `npm run delivery:recheck` (an
"incoming" file in the manifest). It must not move.

**Test fixtures.** Every file under `fixtures/` and `tests/fixtures/` is read
by a test or script (the `new-shops-*` fixtures by name built from a shop id,
`fixtures/regions/` and `fixtures/catalogue/` by folder). None is orphaned.

**Tests.** 292 test files. The skipped suites are all `describe.skipIf(!built)`
(skipped only when the page has not been built), not tests of code that no
longer exists. None deleted.

**Stray files.** None at the root or in `demo/` (`CNAME`, `robots.txt`,
`manifest.webmanifest`, `sw.js`, `favicon.svg`, `template.html` are all
served or read by the build). Every `demo/*.ts` module is imported.

**Build output committed.** None. `dist-demo/` is a build output
(`tsconfig.demo.json` `outDir`) and was already gitignored and untracked;
nothing reads it from git (vitest excludes it).

## 3. Misplaced

  (small cuts). Tests name both by path, and the brief forbids moving test
  files, so both stay; the docs index and README say which is which.
- Social post scripts sit among the build scripts in `scripts/`. Left: see
  section 2 (the manifest names them by the `scripts/social-*.ts` pattern,
  and they import shared helpers beside them).
- Region code: `scripts/region-harvest.ts`, `build-region-*.ts`,
  `bundle-region.ts`, `regionPages.ts`, `regionSite.ts` run in the region
  crawls and the deploy. Not moved (workflow and build paths).
- Probes (`*-probe.ts`) are `package.json` scripts and some run in
  workflows. Not moved.
- `README.md` opened with two long owner action sections from August and
  September (the environment cache bug and the commit signing key). Both are
  kept in full in `docs/OWNER-STEPS.md` §3c and `docs/DECISIONS.md` D10, D12,
  D16, D17, D19; the README now points there.
