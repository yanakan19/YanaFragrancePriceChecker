# Every file a workflow step or a build script writes and commits to the branch,
# the files the page build writes that are built at deploy time instead, and the
# social posts' pictures and videos, which are rendered and never committed.
#
# This is the one list. scripts/commit-and-push.sh reads it (through
# scripts/generated-files.sh) to decide how to settle a push conflict, the
# build scripts refuse to write a file it does not name (writeGenerated in
# scripts/generatedFiles.ts), the workflows' "commit the rebuilt app" steps
# take their path list from it, and tests/generatedFiles.test.ts fails when a
# build writes a committed file that is missing here or a workflow commits a
# path it does not cover. Run #592 (2026-10-04) died because the sitemap was
# written by the build but missing from the script's own copy of this list.
#
# Adding a generated file: add a line here in the same commit. A "deploy" or
# "social" file also needs a line in .gitignore (tests/generatedFiles.test.ts checks).
#
# Columns: policy, path, who writes it (free text, for people).
#
#   rebuild   Built from other committed files by `npm run rebuild`. On a push
#             conflict it is rebuilt from the merged inputs, never merged, and
#             "Commit rebuilt app" commits every rebuild path.
#   incoming  Machine-written data that no build can recreate. On a push
#             conflict the incoming (already pushed) side is kept; the next run
#             writes it again.
#   manual    Machine-written source. A push conflict stops for a person.
#   deploy    Written by `npm run demo` and never committed: gitignored, and
#             built from the committed files by .github/workflows/deploy-pages.yml
#             before every deployment. No workflow may commit one, and
#             scripts/commit-and-push.sh refuses a caller that names one.
#   social    A social post's picture or video (docs/DECISIONS.md D28, from
#             2026-10-08). Rendered from the post's committed text (its HTML or
#             SVG, check.json, pictures.json) by scripts/social-*.ts and never
#             committed: gitignored, made on demand with
#             `npm run social:render -- social/posts/<folder>`, and rendered by
#             .github/workflows/social-pictures.yml into a private workflow
#             artifact. scripts/commit-and-push.sh refuses a caller that names one.
#   source    Committed by people and never written by a build. Listed only so
#             that a wider pattern further down (demo/*.html) does not claim it;
#             first match wins, so it goes above that pattern.
#
# A path ending in / is a folder (everything under it). * matches any run of
# characters, / included. Lines starting with # are comments.

# (catalogue/<shop>.json), its harvest report, its catalogue, price history,
# report and product addresses. No UK path, no page. So the region crawls and the

# (2026-10-09) the deploy builds /us/ and /in/ from these folders.
